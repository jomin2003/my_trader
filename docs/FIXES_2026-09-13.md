## Known remaining (documented, not fixed — each is a deliberate follow-up)

- **Positions are booked at signal price, not fill price** — after a MARKET entry, fetch
  the fill (`get_order_by_id`) and recompute SL/target/R from it.
- **Reconciler/order_state_machine are still unwired** — on boot, reconcile broker
  positions vs `_OPEN_POSITIONS` (the modules exist and are tested; wiring is a deploy
  decision).
- **Two config systems** (`config_registry` vs `settings.py`): `config_validator` should
  validate the registry's resolved values.
- **No consecutive-fetch-failure alarm**: if the token dies at 08:30 the bot silently
  does nothing all day; `/readyz` should do one authenticated Dhan call.
- **`_supertrend_dir` is still an EMA approximation** — replacing it changes behavior
  and must be re-validated on its own.

## New strategies (see docs/RESEARCH_2026-09.md §7)

- **MR_VWAP_FADE** — Connors-style intraday mean reversion (fade ≥2σ VWAP extensions
  with RSI(2) confirm, volume-spike veto). Exit profile RR 0.8 — the first high-WR /
  small-RR strategy in a book that was 100% momentum on the most mean-reverting
  universe in the market.

  volume gates (levels seeded daily by the 09:20 cron).

(`ALLOWED_STRATEGIES` / `PROFITABLE_ONLY` governance unchanged) until they pass the
same walk-forward bar as everything else. Run `research/ab_test.py` /
`param_sweep.py --walk-forward`
on them before even considering promotion.
